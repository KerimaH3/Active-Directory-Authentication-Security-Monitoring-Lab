# Active-Directory-Authentication-Security-Monitoring-Lab
  # Overview
  This project demonstrated the deployment and administration of a Windows Active Directory environment using Windows Server 2022 and w Windows clinet. 

  The lab focuses on domain authentication, user administration, Group Policy, account lockout controls, Remote Desktop access, and Windows Security Event Monitoring. 

  A domain user account was used to stimulate successful authentication attempts, account lockout, administrative recovery, and successful access after recovery.
